First release of plumb. Trace a VM by UUID, name, fixed IP or floating IP from Keystone, Nova and Neutron down to the OpenSDN Config API, the control nodes and the vRouter agent, with `plumb trace`. Check whether two VMs can reach each other with `plumb path`, what a machine can reach with `plumb doctor`, and how each layer looks when it breaks with `plumb demo`.
